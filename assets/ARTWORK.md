# 池塘美术来源

- 工具：Codex 内置 imagegen（未使用 API / CLI 回退）
- 输出：`assets/pond.png`（原图）；运行时使用压缩后的 `assets/pond.jpg` 及其内嵌版本 `assets/pond-data.js`
- 用途：锦鲤池塘的静态水底、荷叶与荷花背景；锦鲤、乌龟、蝴蝶等贴图由 `art.js` 程序化绘制，水波、焦散与天气由 WebGL 着色器生成。
- 未使用视频截图或原作者的素材作为生成输入。
