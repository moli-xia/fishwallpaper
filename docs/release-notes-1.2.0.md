一方碧潭作桌面：锦鲤悠游、云影掠过、雨打荷叶，轻点一下就来抢食。

## 下载

| 平台 | 文件 |
| --- | --- |
| macOS 12+（Apple 芯片） | `BichiKoiPond-1.2.0-macOS.dmg` — 拖进「应用程序」后运行；首次打开请右键 →「打开」 |
| Windows 10 / 11 | `BichiKoiPond-1.2.0-Windows.zip` — 解压整个文件夹，运行 `BichiPond.exe` |
| Android 7.0+ | `BichiKoiPond-1.2.0-Android.apk` — 安装后打开即进入动态壁纸预览，点「设置壁纸」 |
| 浏览器 / Wallpaper Engine | `BichiKoiPond-1.2.0-Web.zip` — 打开 `index.html`，或导入 Wallpaper Engine |

`SHA256SUMS.txt` 为各文件的校验值。

## 这一版

- 云影：成团的云影随风移过池面，遮住处变暗变冷、焦散与波光消失，移走后阳光回来。
- 雨天：荷叶积水与水珠、石头湿润反光、雨打荷叶的水花与颤动、雨雾，大雨时闪电与雷声。
- 鱼影更清晰：青绿色调，贴底的鱼影深而锐利，浮在水面的更柔和。
- 更真实的锦鲤与青鲢：圆钝的头部、逐片可见的鳞片，纯红、黄金、墨鲤也有鳞纹。
- 新增池边的小螃蟹。
- Android 改为真正的桌面动态壁纸：原生分辨率 60 帧，轻点桌面空白处投喂，被遮挡时停止绘制。
- 新增 Windows 桌面动态壁纸（位于桌面图标之下，托盘图标控制）。
- macOS：修复桌面壁纸上的控件无法点击；菜单栏天气、暂停、登录时启动；多窗口实时同步。
